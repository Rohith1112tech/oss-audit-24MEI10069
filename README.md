📌 Project Overview 

For this project, the aim is to study and understand Git as an open source software. The aim is not only to learn what Git actually does, but also why it was created and how it contributes to the broader open source ecosystem. 

Git is a distributed version control system that tracks code changes and enables collaborative work on applications in a shared environment. It is an essential tool for software engineering that is applicable to virtually all real-world projects. 

🎯 Objectives 

To understand the idea behind open-source software. To Git license and support freedom of use. To explore working of Git on Linux system. To understand the ecosystem around Git. To compare open-source tools and proprietary software. To practice Linux concepts on the shell-script.
